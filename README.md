# mkv2mp4

Конвертер видео в MP4 и нарезка роликов для TikTok, для macOS (Apple Silicon): приложение на
Flutter и консольная утилита, общее ядро на Rust. Внутри — собственная статическая сборка
ffmpeg, на целевом Маке ничего устанавливать не нужно.

На вход принимаются MKV, MP4, M4V, MOV, AVI, WebM, TS/M2TS/MTS, FLV, WMV, MPEG, 3GP и OGV.
Если результат совпал бы с исходником или с другим файлом очереди (например, `a.avi` и `a.mp4`
в одной папке), к имени добавляется `_mp4`, `_mp4_2`, … — исходники никогда не перезаписываются.

По умолчанию делает **ремукс**: видео перекладывается в MP4 без перекодирования — за секунды
и без потери качества. Аудио, которое плееры Apple не воспроизводят из MP4 (Opus, FLAC, DTS,
Vorbis и т. п.), перекодируется в AAC; AAC, MP3, AC-3, E-AC-3 и ALAC копируются как есть.
Субтитры переводятся в `mov_text`, а если не получается — отбрасываются.
Режим полного перекодирования использует аппаратный кодировщик macOS (VideoToolbox).

## Ролики для TikTok

Главный экран приложения (и `mkv2mp4 --shorts`) нарезает видео на вертикальные ролики.
Конвертация в MP4 — дополнительный экран: кнопка «…» в углу или «Файл → Конвертация в MP4…» (⇧⌘M).


- кадр 1080×1920: видео целиком по центру, чёрные поля сверху и снизу;
- субтитры крупным белым текстом на нижнем поле, текст из дорожки субтитров MKV
  (дорожка выбирается; субтитры-картинки PGS/VobSub не подходят) или распознанный из речи
  (см. ниже);
- текст страницами по две строки, шрифт TikTok Sans SemiBold (OFL, встроен, `core/fonts/`);
  слова появляются по мере речи, звучащее подсвечено салатовым. Стиль выбирается («Текст:» в приложении,
  `--captions reveal-highlight|reveal|highlight|whole` в CLI): по мере речи с подсветкой
  (по умолчанию), только по мере речи, только подсветка или реплика целиком. Время слов берётся из Whisper (DTW), для субтитров из файла оценивается по длине текста;
- длина ролика задаётся (по умолчанию до 60 с), разрез ставится в паузе между репликами;
- результат в папке `<имя>_tiktok/`: `<имя>_01.mp4` + `<имя>_01.srt` на каждый ролик,
  полная транскрипция `<имя>.srt` и `<имя>.txt`.

Наш ffmpeg собран без libass/freetype, поэтому текст рисуется в Rust (cosmic-text) в PNG-полосы, которые ffmpeg накладывает на кадр (`core/src/shorts.rs`).

```sh
mkv2mp4 --shorts --sub 1 --max-len 45 movie.mkv   # субтитры со второй дорожки, ролики до 45 с
mkv2mp4 --shorts --speech movie.mkv               # текст распознаётся из речи
```

### Лучшие моменты

Режим «Нарезка: лучшие моменты» (в CLI `--best`) нарезает не всё видео подряд, а только
самые цепляющие фрагменты по 60–180 с (`core/src/highlights.rs`), в два шага:

1. **Кандидаты.** ffmpeg считает громкость по секундам и монтажные склейки
   (`core/src/media_signals.rs`, ~10 с на 20-минутную серию). Claude Haiku получает расшифровку
   с этими сигналами (громко/тихо, число склеек, отрезки без слов) и предлагает до двух
   кандидатов на минуту видео с оценкой по тексту.
2. **Кадры.** Для каждого кандидата делается раскадровка (кадр каждые 2 с, листы 4×4), Haiku
   смотрит её и оценивает картинку: сильное ли начало, выразительны ли лица и реакции.
   Итог — среднее оценок по тексту и по кадрам; остаются лучшие (не ниже 5,5, примерно
   один момент на 2 минуты видео).

Границы подгоняет код: по репликам с небольшим запасом, в пределах 60–180 с, без пересечений.
Описание моментов (время в исходнике, оценки, название для подписи, почему выбран, что на
экране) лежит в `<имя>_моменты.txt`. Нужен ключ Claude; без него или при ошибке API видео
нарезается подряд с предупреждением, а если не удалась только оценка кадров — отбор идёт по тексту.

### Распознавание речи (Whisper + Claude Haiku)

Если в файле нет текстовых субтитров, приложение само выбирает «Распознать речь». Этот пункт
можно выбрать и вручную в списке субтитров. Дальше (`core/src/transcribe.rs`):

1. ffmpeg извлекает выбранную аудиодорожку (16 кГц, моно).
2. **Whisper** (whisper.cpp, встроенный `whisper-cli`, работает локально на GPU) распознаёт
   речь в реплики с таймингами. Модель скачивается один раз при первом распознавании
   в `~/Library/Application Support/MKV2MP4/models/` (по умолчанию `large-v3-turbo-q5_0`, 574 МБ).
3. **Claude Haiku** (`claude-haiku-5-5`) вычитывает текст фрагментами по 80 реплик: исправляет
   неверно услышанные слова и пунктуацию, удаляет «галлюцинации» Whisper на тишине. Тайминги
   не меняются. Если ключа нет или запрос не удался, остаётся текст Whisper, а в списке
   появляется предупреждение.

Ключ и настройки хранятся в `.env`:

```sh
ANTHROPIC_API_KEY=sk-ant-...      # ключ Claude API; пусто — без вычитки
WHISPER_LANGUAGE=auto             # ru, en, … или auto
WHISPER_MODEL=large-v3-turbo-q5_0 # large-v3-turbo, medium, small, base
```

Приложение читает `~/Library/Application Support/MKV2MP4/.env`: файл создаётся с пустым ключом,
открыть его можно кнопкой «Открыть .env» внизу окна. Консольная утилита сначала смотрит
`./.env` (в корне проекта уже лежит заготовка, в git она не попадает, образец в `.env.example`).
Переменные окружения важнее обоих файлов.

## Структура

| Путь | Что это |
|---|---|
| `core/` | Rust-библиотека: выбор стратегии, запуск ffmpeg, прогресс, отмена |
| `core/src/shorts.rs` | Нарезка на ролики: дорожки, субтитры, план разрезов, отрисовка текста |
| `core/src/transcribe.rs` | Распознавание речи: Whisper, вычитка через Claude Haiku, чтение `.env` |
| `cli/` | Консольная утилита `mkv2mp4` |
| `app/` | Flutter-приложение (Riverpod + freezed), связь с Rust через flutter_rust_bridge |
| `app/rust/` | API для Dart (`src/api/convert.rs`, `src/api/shorts.rs`) |
| `app/integration_test/` | Тесты внутри приложения (`--dart-define=TEST_DIR=…` / `SHORTS_FILE=…`) |
| `vendor/build-ffmpeg.sh` | Сборка статического ffmpeg (LGPL) в `vendor/bin/ffmpeg` |
| `vendor/build-whisper-cli.sh` | Сборка статического whisper-cli (whisper.cpp, MIT, Metal) в `vendor/bin/whisper-cli` |
| `app/macos/icon/` | Иконка: исходник `app_icon.svg` и `build-icon.sh`, который рендерит PNG в `AppIcon.appiconset` |
| `build-app.sh` | Полная сборка: ffmpeg, whisper-cli → приложение → `dist/MKV2MP4.dmg` |

## Сборка

Нужны Xcode, rustup (`brew install rustup && rustup default stable`), cmake (`brew install cmake`,
для whisper.cpp), Flutter 3.38.6 (через fvm) и `cargo install flutter_rust_bridge_codegen`.

```sh
./build-app.sh            # → dist/MKV2MP4.dmg
cargo install --path cli  # консольная утилита
```

Во Flutter 3.38.0 с Xcode 27 сборка падает на проверке архитектур, нужна 3.38.6+.
Приложение собирается только под arm64, так как встроенный ffmpeg собран под arm64.

После изменения `app/rust/src/api/` или моделей Dart:

```sh
cd app
flutter_rust_bridge_codegen generate
dart run build_runner build -d
```

## Консольная утилита

```sh
mkv2mp4 movie.mkv                     # → movie.mp4 рядом
mkv2mp4 -R ~/Movies -o ~/Movies/mp4   # рекурсивно, в отдельную папку
mkv2mp4 -r movie.mkv                  # полное перекодирование
mkv2mp4 -f movie.mkv                  # перезаписать существующий .mp4
```

ffmpeg ищется рядом с программой, затем в PATH; путь можно задать в `MKV2MP4_FFMPEG`.
